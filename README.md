# Hackathon

A starter web project using [Bootstrap 5.3](https://getbootstrap.com/) (loaded via CDN).

## Structure

```
index.html      — main page, Bootstrap CSS/JS wired in
css/style.css   — custom styles on top of Bootstrap
js/main.js      — custom JavaScript
```

## Run locally

Open `index.html` directly in a browser, or serve it:

```sh
npx serve .
# or
python3 -m http.server 8000
```
