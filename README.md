# Hackathon

A starter web project: **FastAPI** (Python) backend + **Bootstrap 5.3** frontend (HTML/CSS/JS, Bootstrap via CDN) + **SQLite** storage.

## Structure

```
main.py             — FastAPI app: serves the page, JSON API, SQLite helpers
templates/          — HTML pages (Jinja templates), Bootstrap wired in
static/css/         — custom styles on top of Bootstrap
static/js/          — frontend JavaScript (calls the API with fetch)
requirements.txt    — Python dependencies
.env.example        — copy to .env for secrets/config
app.db              — SQLite database (created on first run, gitignored)
```

## Setup (once)

```sh
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

## Run

```sh
source venv/bin/activate
python main.py          # or: uvicorn main:app --reload --port 5001
```

Then open http://127.0.0.1:5001 — the page includes a working demo that
creates, lists, and deletes items through the API, stored in SQLite.

Interactive API docs (auto-generated by FastAPI): http://127.0.0.1:5001/docs

## API

- `GET /api/health` — liveness check
- `GET /api/items` — list items
- `POST /api/items` — create an item, JSON body: `{"name": "..."}`
- `DELETE /api/items/{id}` — delete an item

Example:

```sh
curl -X POST http://127.0.0.1:5001/api/items \
  -H 'Content-Type: application/json' \
  -d '{"name": "first item"}'
```
